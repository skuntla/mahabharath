# Character Bible

Profiles are provisional descriptions. The actual image references must be stored in `characters/references/` and reviewed before being marked approved.

For each recurring character, maintain an approved master portrait, alternate views, expressions, and age-specific references when necessary. Use those images directly for future scene generation whenever the image tool supports it.
