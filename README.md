# Mahabharata for Agastya

A child-friendly, faithful, illustrated retelling of the Mahabharata, one meaningful event per bedtime episode.

- Audience: Agastya, age 5, enjoys deeper reasoning.
- Episode length: approximately 5–7 minutes, flexible.
- Plan: roughly 200–250 episodes; no hard limit.
- Visuals: 8 separate 3:4 portrait illustrations per episode, not collages.
- Art: warm, cinematic, kid-friendly animated storybook style with believable proportions.
- Each episode: story, one central lesson, two thinking questions, next-day teaser.

**Continuity rule:** Before producing illustrations, load approved character reference images and profiles. Text-only prompts are not a substitute for image references. Do not assume an image was approved just because it was generated.

See docs/ and characters/ for the production rules. Day 1 focuses on Hastinapura, King Shantanu, and the first mysterious encounter by the river.
