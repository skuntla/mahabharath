# Episode Production Checklist

## Before writing
- [ ] Read series bible, style guide, episode plan, prior episodes.
- [ ] Confirm day number, narrative boundary, and one main event.
- [ ] List cast and match every named visible character to a profile.
- [ ] Confirm whether actual approved reference images are accessible.
- [ ] For new major cast: design, version, save, and obtain approval first.

## Before illustrations
- [ ] Story checked for fidelity, chronology, age suitability, one lesson, two questions, teaser.
- [ ] Each scene tied to a different story beat; no spoilers.
- [ ] Character age, costumes, props, and environment continuity checked.
- [ ] Distinct 3:4 images, no collages, no lettering.
- [ ] Image-reference inputs actually supplied when supported.

## Before marking complete
- [ ] Story exists and is approved.
- [ ] All required image files exist and are visually reviewed.
- [ ] Manifest lists every asset, approval, and issue accurately.
- [ ] GitHub paths and commit verified.
- [ ] Next episode handoff updated.
